The exploratory investigation that identified *why* the classifier false-positives. Findings,
including dead ends and corrections, are in [`../experiment-log.md`](../experiment-log.md).

Stage 2 (`../stage2_autosearch/`) formalises what was learned here into a repeatable pipeline.

## Running

```bash
uv run python stage1_manual/exp_noise_sweep.py     # from the repo root
```

Each script writes its generated images to `../outputs/<experiment>/` (gitignored) and prints a
score table. `score.py` is the shared helper: it loads the provided checkpoint once and returns
full probability vectors.

## The experiments, in order

| script | experiment | what it established |
|---|---|---|
| `score.py` | E000 | baselines. dog > cat on all five images; `forest` is the *farthest* from dog, killing an early hypothesis |
| `exp_text_only.py` | E001 | rendered word content is irrelevant — "Dog" scores worse than "Tree" or gibberish. No OCR ability |
| `exp_shape_probe.py` | E002 | shape is irrelevant — ASCII art of a dog scores worse than ASCII art of a tree |
| `exp_prior_probe.py` | E003 | **the breakthrough.** Smooth featureless images cluster at the model's prior; high-frequency noise crosses to `dog` at 0.68 |
| `exp_noise_sweep.py` | E004 | noise on real images crosses on all five. Salt-and-pepper never crosses — the key negative control |
| `exp_watermark.py` | E005 | watermark density and glyph scale dominate opacity; a large wordmark does nothing |
| `exp_scale_frequency.py` | E006 | tiling vs cropping vs downscaling. Judge against the prior, not each image's own baseline |
| `exp_collage.py` | E007 | grid **lines alone** beat every elaborate construction |
| `exp_collage2.py` | E008 | mixed-source collage; the gutters are required, not the collage |
| `exp_collage3.py` | E009 | coarse grids; line colour preference inverts with density |
| `exp_collage_seeds.py` | E010 | seed and source-diversity sensitivity |
| `exp_watermark2.py` | E011 | watermark search at realistic density; rotation angle is a major lever |

## Note

These are exploratory scripts, kept as the historical record of the investigation. They hardcode
their own parameter sweeps rather than reading a config. That limitation is precisely what
motivated Stage 2 — and it caused a real error: `exp_collage3.py` tested grid 8 at a single seed,
measured 0.46, and concluded it "fails". The automated search later found grid 8 reaching
`dog` 0.9991 with a different seed.
